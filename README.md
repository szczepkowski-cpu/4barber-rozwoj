# 4barber-rozwoj

Makiety rozwoju sklepu 4barber.pl — punkt wyjścia to obecny sklep (Shoper Premium), oglądany read-only.
Podgląd: https://szczepkowski-cpu.github.io/4barber-rozwoj/

## Co tu jest
- `index.html` — galeria wersji (start).
- `przeglad-2026-09-27.html` — przegląd obecnego sklepu ze zrzutami (telefon 390 / desktop 1440) i diagnozą CRO.
- `pdp-v1.html` (biała, nowa kolejność) · `pdp-v4.html` (biała, technikalia w prawej szpalcie jak dziś) · `pdp-v3.html` (czarna „karta techniczna”, rekomendacja) —
  propozycje karty produktu **Maszynka WMARK NG-139 Czarna**; statyczny HTML+CSS+minimalny JS. `pdp-v2.html` wycofana z galerii (decyzja: jedna czarna), plik zostaje.
- `raport-2026-09-27.pdf` (+ `.html`) — PDF z przeglądem, propozycjami i rekomendacją.
- `dane/ng139-2026-09-27.md` — wszystkie fakty produktu (ceny, parametry, opinie, dostawa) z żywego sklepu, z datą odczytu.
  W makietach nie ma żadnej liczby, której tu nie ma.
- `assets/` — zdjęcia produktu ze sklepu (+ wycinanki z przezroczystym tłem), logo, zdjęcia barberów z opinii, produkty do zestawu.
- `zrzuty/` — zrzuty audytu i każdej wersji.
- `PRODUCT.md`, `.impeccable/` — kontekst produktu i kontrakty kierunków (Impeccable).

## Zasady
